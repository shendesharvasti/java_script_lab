Advanced Self-Correcting RAG

The workflow is designed to retrieve documents, grade their relevance, generate an answer, and verify whether the answer is supported by evidence.

  • FAISS similarity search with Hugging Face embeddings.
  • Relevance grading and query rewriting when retrieval is weak.
  • Answer support verification and a revision path.
  • Structured decisions with Pydantic and graph routing with LangGraph.
